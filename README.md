# TikTok Live Stream & Chat Monitor

A standalone Python desktop application built to track and display real-time TikTok Live events, chat messages, viewer counts, and gifts in a clean interface.

## Features
- **Live Chat Feed:** Real-time comment monitoring and event logging
- **Engagement & Gift Tracking:** Tracks incoming gifts, likes, and viewer count updates
- **Desktop GUI:** Lightweight, standalone interface built for easy stream monitoring

## Built With
- **Python** — Core application logic and event handling
- **Tkinter** — Desktop graphical user interface
- **[TikTokLive](https://github.com/isaackogan/TikTokLive)** — Unofficial Python client used to connect to TikTok LIVE Webcast events in real time
